## Settings

| Setting             | Value    |
| ------------------- | -------- |
| **Semicolons**      | No       |
| **Quotes**          | Single   |
| **Tab Width**       | 2 spaces |
| **Trailing Commas** | ES5      |
| **JSX Quotes**      | Single   |
| **Print Width**     | 80       |

File-specific overrides: Markdown always wraps prose, YAML uses no single quotes
with 2-space indent, and JSON has no trailing commas.
